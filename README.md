# 📊 Student Performance Data Analytics Dashboard

An interactive data analytics project developed using Python and Streamlit to analyze student academic performance and explore the impact of study hours, parental involvement, and other factors on student scores.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- Excel

## ✨ Features
- Student performance analysis
- Data cleaning and preprocessing
- Interactive data visualization
- Performance insights and KPIs
- Analysis of factors affecting student scores

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
